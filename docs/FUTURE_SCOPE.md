# ChangeFrame — Future Scope

## Real data adapters

- Procore and Autodesk Construction Cloud issue import
- IFC/BIM and CAD geometry ingestion
- Primavera and Microsoft Project schedule import
- cost-code and contract-system adapters
- authenticated multi-project storage and tenant isolation

## Stronger verification

- discipline-specific engineering rule packs
- source-linked unit-rate and productivity assumptions
- schedule-network float analysis
- multiple simultaneous constraint types
- solver-assisted routing and clash detection
- calibrated uncertainty and mandatory engineering-review thresholds

## Collaboration and artifacts

- immutable revision history and decision supersession
- architect, engineer, owner and subcontractor review stages
- RFI, submittal and decision-package drafts
- PDF export and downstream publishing with a separate human execution gate

These capabilities must extend the generic runtime contracts. They must not reintroduce scenario-specific branches or hidden canned answers.
